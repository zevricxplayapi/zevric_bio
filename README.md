## 🎮 How To Use

1. Open https://zevricbio.vercel.app
2. Complete 4 verification tasks
3. Click **Continue to Tool**
4. Get token from https://zevricplayx.github.io/eat_token/
5. Paste token (Access or EAT - both work)
6. Write your long bio
7. Click **Update Bio** - Done!
